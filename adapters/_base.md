# 공통 에이전트 규칙

본 에이전트는 멀티 에이전트 공유 규칙 저장소인 **AgentCode** 의 범용 규약을 따릅니다.

## 핵심 원칙

1. **안전성 우선** — 모든 시스템 코드는 안전성과 무결성을 최우선적으로 검증해야 합니다.
2. **점진적 변경** — 불필요하게 넓은 범위의 리팩토링이나 구조 변경은 지양하며, 요구사항에 해당하는 최소 범위를 정확하게 점진적으로 변경합니다.
3. **규칙 엄수** — 제공된 정책(Policy)과 워크플로우를 절대적으로 준수합니다.
4. **임의의 가정 금지** — 지시한 정확한 범위 내에서만 작업을 수행하고, 추가적인 조치가 필요해 보인다면 반드시 사전에 질문하고 승인받은 뒤에만 움직입니다.

## 정책 및 스킬 참조

- 에이전트는 로드된 환경의 **스킬(Skills)** 및 **정책(Policies)**을 우선적으로 숙지하고 따릅니다.
- `manifest.yaml`에 정의된 의존성 구조를 확인합니다.

## 참조 우선순위

- 공통 기본값은 `.ai/` 아래의 정책과 스킬을 기준으로 해석합니다.
- 프로젝트별 예외, 보강 규칙, 로컬 스킬은 `.ai-local/`에서 추가로 로드합니다.
- 동일한 주제에서 `.ai/`와 `.ai-local/`의 지시가 충돌하면 `.ai-local/`을 우선하고, `.ai-local/`에 정의가 없으면 `.ai/` 기본값을 따릅니다.

## 복잡한 의사결정 요청

결정 사항이 3개 이상이거나 옵션 비교 설명이 길면 `docs/<주제>.html`에 결정 폼을 생성한다. 보일러플레이트·사용 가이드: `.ai/adapters/templates/`.
